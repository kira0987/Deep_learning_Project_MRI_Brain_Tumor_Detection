# Deep_learning_Project_MRI_Brain_Tumor_Detection
An end-to-end Deep Learning project developed during the 2nd Year Data Science Engineering Cycle (4DS6 - Semester 2) at ESPRIT. This repository features data exploration, quality assessment, image augmentation, custom CNN modeling, and fine-tuning using VGG16 Transfer Learning for multi-class brain tumor classification from MRI scans.📌 Project OverviewBrain tumors are critical medical conditions requiring early and accurate diagnosis[cite: 1]. Manual MRI scan inspection is time-consuming and subject to inter-observer variability[cite: 1]. This project implements automated deep learning pipelines to detect and classify brain MRI scans into four target categories[cite: 1]:Glioma Tumor[cite: 1]Meningioma Tumor[cite: 1]Pituitary Tumor[cite: 1]No Tumor (Healthy scans)[cite: 1]📂 Dataset DetailsThe dataset comprises 6,726 unique MRI images across four distinct classes after removing duplicate files[cite: 1]:CategoryImage CountGlioma1,621[cite: 1]Meningioma1,645[cite: 1]No Tumor2,000[cite: 1]Pituitary1,757[cite: 1]Total7,023 (6,726 post-deduplication)[cite: 1]🔬 Exploratory Data Analysis & Quality ChecksDuring data exploration, several checks were executed to evaluate image structural properties[cite: 1]:Dimensionality Analysis: Image widths ranged between $150$–$800$ pixels and heights between $160$–$1,080$ pixels[cite: 1]. All images were standardized via resizing to $224 \times 224$ pixels[cite: 1].Brightness & Contrast: Histogram distributions indicated healthy intensity levels peaking around 40 grayscale value[cite: 1]. High-contrast images ($255$–$259$ range) constituted the vast majority ($5,394$ images)[cite: 1].Data Integrity & Sharpness:Corrupted Images: $0$ corrupted images detected[cite: 1].Duplicate Images: $297$ duplicate images identified via MD5 hash comparison and deleted to prevent overfitting[cite: 1].Sharpness Assessment: Evaluated using Fast Fourier Transform (FFT) magnitude spectrum summation[cite: 1]. All log-scaled values exceeded $7.0$ ($>10^7$), confirming high edge resolution across the dataset[cite: 1].🛠️ Data Preprocessing & AugmentationThe data preparation workflow consists of:Deduplication: Removal of exact cryptographic duplicates via MD5 hashing[cite: 1].Resizing & Normalization: Standardized image tensor shapes to $(224, 224, 3)$ with pixel normalization to range $[0, 1]$[cite: 1].Data Augmentation: Brightness ($\pm 10\%$) and Contrast ($\pm 10\%$) adjustments applied dynamically via PIL ImageEnhance[cite: 1].Data Splitting:Training Set: 80%[cite: 1]Validation Set: 10%[cite: 1]Test Set: 10% ($673$ images)[cite: 1]🏗️ Model Architectures1. Custom CNN (Trained from Scratch)Architecture: 3 Convolutional Blocks ($\text{Conv2D} \rightarrow \text{ReLU} \rightarrow \text{MaxPooling2D}$) with filter dimensions 32, 64, and 128[cite: 1].Classifier: Flatten $\rightarrow$ Dense(128, ReLU) $\rightarrow$ Dropout(0.5) $\rightarrow$ Dense(4, Softmax)[cite: 1].Optimization: Adam ($\alpha = 0.0001$), Sparse Categorical Crossentropy, Batch Size 32[cite: 1].2. VGG16 (Transfer Learning)Base Model: Pre-trained VGG16 on ImageNet with frozen lower layers[cite: 1].Fine-Tuning: Unfrozen top 3 convolutional layers for domain adaptation[cite: 1].Classifier Top: Input(224, 224, 3) $\rightarrow$ VGG16 Base $\rightarrow$ Flatten $\rightarrow$ Dropout(0.3) $\rightarrow$ Dense(128, ReLU) $\rightarrow$ Dropout(0.2) $\rightarrow$ Dense(4, Softmax)[cite: 1].Regularization: Early Stopping with a patience of 3 based on validation loss[cite: 1].📊 Results & Comparative AnalysisEvaluation executed on the holdout test set ($673$ samples)[cite: 1]:MetricCustom CNN from ScratchVGG16 Fine-TunedOverall Accuracy92%[cite: 1]96%[cite: 1]Precision (Macro Avg)92%[cite: 1]96%[cite: 1]Recall (Macro Avg)92%[cite: 1]96%[cite: 1]F1-Score (Macro Avg)92%[cite: 1]96%[cite: 1]Test Loss~0.1617[cite: 1]0.1220[cite: 1]Class-Wise F1-Score BreakdownClassCustom CNNVGG16 Pre-trainedGlioma0.90[cite: 1]0.95[cite: 1]Meningioma0.83[cite: 1]0.93[cite: 1]No Tumor0.98[cite: 1]0.99[cite: 1]Pituitary0.96[cite: 1]0.97[cite: 1]Conclusion: The fine-tuned VGG16 model yielded superior generalization, resolving accuracy gaps present in the custom CNN (particularly for Meningioma detection, where recall increased from $75\%$ to $96\%$)[cite: 1].💻 Tech Stack & DependenciesLanguage: Python 3.8+[cite: 1]Deep Learning Framework: TensorFlow, Keras[cite: 1]Computer Vision & Processing: OpenCV (cv2), PIL (Pillow)[cite: 1]Data Analysis & Visualization: NumPy, Pandas, Matplotlib, Plotly[cite: 1]Machine Learning Tools: Scikit-Learn[cite: 1]🚀 Getting StartedPrerequisitesEnsure Python 3.8+ is installed.
